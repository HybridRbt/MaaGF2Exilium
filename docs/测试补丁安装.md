# v2.7.2 弹窗测试补丁

适用用户截图版本：软件 v2.16.1、资源 v2.7.2、框架 v5.12.3。包含极限峰值缺员确认、预演介绍关闭、连续处理多个预演；尚未 Windows 实测。此包不更新界面程序、框架、Python、账号及连接配置。

## 安装

1. 等当前任务结束，停止任务并完全退出助手。
   如果已经安装过旧测试补丁，先用旧包的 `rollback.bat` 恢复原资源，再替换 `dialog-patch` 文件夹并安装新版；不要叠加安装。
2. 解压 ZIP，将其中整个 `dialog-patch` 文件夹放进助手安装目录（与 `MaaGF2Exilium.exe`、`interface.json`、`resource`、`python` 同级）。
3. 双击 `dialog-patch/install.bat`，看到 `Patch installed` 才算安装成功；失败信息不要忽略。
4. 重开助手，进入「模拟作战日常」，将「极限峰值：槽位未满仍开始作战」设为 YES 后测试。默认仍为 NO。
5. 预演介绍关闭与多角色连续预演随资源启用，无须额外开关。每场结束后重新选第一项（用户确认已完成项会移到列表尾部），直到第一项奖励已领取。单次任务最多尝试8场，达到上限会提示可能仍有角色未完成，以免战斗失败时无限重复。实测请分别记录缺员确认、介绍关闭及连续预演是否成功；卡住时保留日志及画面。

安装器核对 `interface.json` 的资源版本和被替换文件的 v2.7.2 校验值。若安装包缺少内置 Python、文件被修改、已打过此补丁或版本不符，会停止；不要手动强行覆盖。新选项和语言词条合并到原文件，版本、agent 启动字段、资源路径和其他选项保留。软件/框架版本来自用户截图，安装器不推测二进制版本。

## 复制副本并创建桌面快捷方式

下载 `dialog-copy-installer-v2.7.2-r2` artifact，解压整个包，双击 `install-copy.bat`，选择**原助手安装目录**中的 `MaaGF2Exilium.exe` 或 `MFAAvalonia.exe`。安装器在原目录旁新建独立副本，只在副本中回滚旧测试补丁、安装新版，并在当前用户桌面创建指向副本的快捷方式；不启动助手或运行游戏。若曾安装失败，重试时仍选择原目录，不能选择先前的「补丁测试」副本。

2026-10-01 用户报告 `预演.json` 的 v2.7.2 文件校验失败。旧校验会将 Windows CRLF 换行或 UTF-8 BOM 当作内容改动。r2 仅容忍这两种文本表示差异，真正内容差异仍拒绝；备份和回滚保留原始字节。尚不能仅据报错断定用户文件差异就是换行，需以重试结果核实。底层 Python 输出会同时写入副本 `dialog-patch/apply-output.log`（回滚为 `rollback-output.log`），并显示在失败弹窗中。

复制与快捷方式脚本尚未在 Windows 执行验证。

## 回滚

完全退出助手，双击 `dialog-patch/rollback.bat`，看到 `Original resources restored` 后重新打开。

原文件保存在安装目录 `.dialog-patch-backup`。回滚会还原原文件并移除补丁新增文件；如果安装补丁后又更新资源或手动改过相关文件，回滚会拒绝覆盖，需核对备份后处理。安装前预检全部文件，写入失败时尝试自动恢复。

正式资源更新可能覆盖此补丁；实测期间先关闭自动资源更新，避免混入不同版本。助手仍显示原资源 v2.7.2，补丁状态由备份目录及安装成功提示确认。

## 验证边界

云端验证逻辑、三种资源加载、合成 v2.7.2 安装目录上的安装/回滚及配置保留；使用真实 MaaFramework 5.12.3 执行模拟页面，验证连续三个角色（每场带介绍弹窗）、全部已领取时不战斗、战斗失败时达到上限退出。模拟替换了视觉识别及外部通用战斗，不能证明游戏页面识别或实战成功。没有在 Windows 运行批处理、OCR 新截图或执行游戏战斗。此包是候选测试资源，不是已验证的正式修复版本。
