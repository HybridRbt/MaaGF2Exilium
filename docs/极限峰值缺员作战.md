# 极限峰值缺员作战选项

模拟作战日常新增「极限峰值：槽位未满仍开始作战」，默认 NO。开启后，三个极限峰值0级子群使用独立部署流程，遇到已识别的可部署提示点击确认，保留0人时的部署行为；其他战斗仍使用原来的取消并补人逻辑。

当前确认识别复用旧提示关键词「可部署」和提示区域，确认按钮使用右下区域的「确定/确认」（英文 Confirm）。新版本调度槽缺员的完整提示及按钮尚无原图，以上识别条件需要实机截图核对；不宣称已验证游戏兼容。不会自动填调度位。

验证：三项 unittest；原生 MaaFramework 5.12.3 执行 check_resource.py，中文模拟器、英文模拟器、中文PC资源加载通过。没有运行游戏战斗。

此为源码候选补丁，基于 23cbf0d78c6f04490c2ff8bc3f8417a7b344f141。不要把 assets/interface.json 整份覆盖未知版本的安装目录：安装包会添加版本及运行配置。实际部署应先核对安装资源版本并合并选项与新增流水线。
