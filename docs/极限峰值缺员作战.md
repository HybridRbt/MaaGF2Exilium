# 极限峰值缺员作战选项

模拟作战日常新增「极限峰值：槽位未满仍开始作战」，默认 NO。开启后，三个极限峰值0级子群使用独立部署流程，遇到已识别的可部署提示点击确认，保留0人时的部署行为；其他战斗仍使用原来的取消并补人逻辑。

2026-09-30 用户补充的裁剪截图确认：标题「注意」，正文「还有可部署的武装小组，是否确定开始作战？」，按钮为左侧「取消」、右侧「确认」。中文分支改为全图 OCR 识别「还有可部署的武装小组」，随后全图识别独立的「确认」并点击识别框；不推导裁剪图相对于游戏整窗的坐标。选项入口也接受该提示，可从已显示弹窗的状态接续；确认未生效时重新识别提示，避免取消补人循环。不会自动填调度位。

英文沿用原有 can be deployed / Confirm 覆盖，入口同步允许该提示。截图仅验证中文文字，不证明英文适配。

验证：六项 unittest（含截图文字的人工转录、无「作战开始」时的入口、无关提示/按钮排除、确认重试路径）；原生 MaaFramework 5.12.3 执行 check_resource.py，中文模拟器、英文模拟器、中文PC资源加载通过。没有运行截图 OCR 或游戏战斗；文字测试不能证明游戏 OCR 成功率。
